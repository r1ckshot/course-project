# Issue worker demo

Ця нотатка створена автоматично на основі задачі з GitHub issue.

Задача була описана в issue, а агент виконав мінімальну зміну коду
чи документації, яка закриває критерії приймання.

Результат оформляється як draft pull request. Людина переглядає
diff, запускає перевірки та вирішує, чи об'єднувати зміни в основну
гілку.
